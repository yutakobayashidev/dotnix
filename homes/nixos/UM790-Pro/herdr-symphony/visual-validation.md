フロントエンドの見た目・操作・画面遷移を変更する場合は、次の視覚的な検証も完了条件に含めてください。

1. 撮影にはagent-browserを使い、開始前に `agent-browser skills get core` と `agent-browser record --help` を読んでインストール済みバージョンの操作方法を確認してください。ブラウザセッション名にはIssue識別子のスラッシュと#をアンダースコアに置き換えた名前を使い、他の作業と分離してください。対象画面を開き、変更した操作と期待する表示を実際に確認してください。比較できる既存画面では、同じviewport・データ・操作で変更前後を記録してください。変更前の版が必要なら別worktreeを使い、進行中の変更を巻き戻さないでください。
2. 変更した操作が分かる短い動画（MP4/WebM）またはGIFを `captures/` に保存してください。録画にはagent-browserのrecord機能を使ってください。Playwright MCPが利用可能な場合は追加の動作確認に使えます。静止画の変更前後比較も必要に応じて添え、新規画面は変更後のPreviewとして示してください。テストデータを使い、公開するメディアに認証情報や個人情報が映っていないことを確認してください。
3. PR作成後、既存のPR本文を読み、変更内容を証明するメディアを本文へ添付してください。この環境では `gh pr edit <PR> --attach <file>` を使えます。複数ファイルは `--attach` を繰り返します。本文を整える場合は `--body-file` を使い、既存の説明を保持してください。比較表示の整形には、利用可能ならbefore-and-afterスキルを読んで使用してください。
4. 更新後のPR本文を取得し、添付がGitHub上のURLになっていること、ローカルパスが残っていないことを確認してください。ブラウザでPRを開き、動画またはGIFが表示・再生できることも確認してください。PRには確認した画面・操作・結果を記載してください。
5. 起動・認証・録画・アップロードのいずれかが失敗した場合は、失敗箇所と再現手順をPRに記載し、視覚的な検証を未完了として報告してください。撮影や添付を実施していない状態を完了扱いにしないでください。画面に影響しない変更では、この検証と添付は不要です。
