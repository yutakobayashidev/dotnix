# Firefox

## Wallet profile

The separate `wallet` profile is defined in `modules/features/browser/firefox/wallet.nix` and installs only MetaMask. It has its own extension data, cookies, history, and bookmarks. Firefox Sync and password saving are disabled; startup and new tabs are blank. The ordinary `nix` profile remains the default and retains its existing MetaMask installation until wallet migration has been verified. Chrome and Chromium are unchanged.

Apply with `nix run .#switch`, then open **Firefox Wallet** from the Linux launcher or run `firefox-wallet`. The command uses `-P wallet`; Firefox routes launches to the selected profile, independently of the ordinary profile. The obsolete `-no-remote` option is unnecessary ([Mozilla explanation](https://bugzilla.mozilla.org/show_bug.cgi?id=1906260)). This is a normal persistent profile, not private browsing. Its native Firefox appearance is separate from the `nix` profile's Parfait theme.

The bookmarks toolbar contains [Uniswap](https://app.uniswap.org/), [Aave](https://app.aave.com/), [Safe](https://app.safe.global/), [ENS](https://app.ens.domains/), [OpenSea](https://opensea.io/), and [Revoke.cash](https://revoke.cash/). Official links were checked on 2026-10-22. Bookmark names are empty, matching the existing toolbar convention. `bookmarks.force = true` replaces bookmarks in this dedicated profile on activation; edit `wallet.nix` for persistent changes.

Set up MetaMask interactively in Wallet and verify the expected accounts before removing it from the ordinary profile. Do not put recovery phrases, private keys, or wallet data in Nix or copy the ordinary profile wholesale. ActivityWatch's browser extension is limited to `nix`; the system window watcher can still record Wallet's window titles. Browser profiles do not isolate files from other programs running as the same OS user.

## Everyday profile

### Privacy and history

The `nix` profile's privacy preferences in `modules/features/browser/firefox/default.nix` follow [nyanshiba's user.js at 7e0216b](https://github.com/nyanshiba/firefox-profile-settings/blob/7e0216b218764be55340119e941488224bb26fda/user.js), with current Firefox preference names:

- Strict Enhanced Tracking Protection, SameSite cookie protections, query stripping, and no automatic Storage Access API grants.
- No new browsing/download history or history suggestions. Form history remains available during a session, as in the reference, and is cleared on exit alongside browsing/download history and cache. Disk cache is disabled.
- Cookies, site storage, and site permissions survive exit. Back/forward history is not serialized. In-session undo is limited to five closed tabs and two closed windows. Normal exit clears session recovery files along with browsing history; browser-initiated restarts may preserve session data. This differs from the reference, prioritizing removal of existing history over restoring tabs after a normal exit.
- Add-on, history, and form Sync engines are disabled explicitly as well as listed in `declinedEngines`; bookmarks and other Sync categories are unaffected.
- Camera, microphone, location, notifications, shortcut overrides, and XR default to blocked; screen sharing and PDF scripting are disabled.
- HTTPS-Only, mixed-content blocking/upgrading, and insecure-download blocking follow the reference. OCSP requests are disabled in favor of enforced CRLite checks. DNS uses the system resolver (`network.trr.mode = 5`), so this configuration does not enable Firefox DNS-over-HTTPS.
- Address-bar search suggestions and sponsored top sites are disabled. Ordinary search-bar suggestions remain enabled and private-window suggestions disabled, matching the reference. Telemetry and Studies are not disabled by this configuration.

The modern `privacy.clearOnShutdown_v2` schema combines browsing and download history, so both are cleared rather than reproducing the old separate switches. The reference's standalone authenticated-session clearing switch has no equivalent selection in the modern shutdown schema and is not copied. The migration marker prevents old preferences from overwriting the declared selections. Obsolete TCP rollout flags, third-party session-only/lifetime preferences, DNT, and canvas-capture switches are omitted. Network partitioning is provided by modern Firefox. Historical fingerprinting font exceptions, TLS cipher tuning, and unrelated appearance/performance preferences are not copied.

Apply with `nix run .#switch`, then restart Firefox. Existing history is removed by the configured cleanup on a subsequent clean exit; configuration evaluation alone does not erase it. In Settings → Privacy & Security, verify Strict protection and the shutdown cleanup selections; visit a test page, quit normally, and confirm after reopening that history is empty while a chosen site's login survives. Open-tab and closed-tab recovery during a session, crash recovery, and browser-initiated restarts can still retain URLs. ActivityWatch and other external activity collectors keep separate records; these Firefox preferences do not erase or disable them. The `wallet` profile is unchanged.

### Extensions and appearance

The `nix` profile includes the [linkding extension](https://addons.mozilla.org/en-US/firefox/addon/linkding-extension/), managed in `modules/features/browser/firefox/extensions.nix`.

The `nix` profile includes [ChatGPT Markdown Exporter](https://github.com/devcxl/chatgpt-markdown-exporter) for exporting individual or multiple ChatGPT conversations as Markdown. Its Mozilla Add-ons XPI is pinned by version and SHA-256 in `modules/features/browser/firefox/extensions.nix`. Apply with `nix run .#switch`, then restart Firefox and open ChatGPT to use the export button or the extension's popup.

New tabs open `https://home.yutakobayashi.com/` through New Tab Override. The extension and its settings are managed by Home Manager; edit the URL in `modules/features/browser/firefox/default.nix` to change it. Apply with `nix run .#switch`, then restart Firefox.

Containers are defined in `modules/features/browser/firefox/containers.nix`, following natsukium's Containerise setup. The blue `school` container automatically opens `nlobby.nnn.ed.jp` and `www.nnn.ed.nico`; the red `work` container automatically opens GitHub's `Litela-HQ` organization and its repositories (`github.com/orgs/Litela-HQ` and `github.com/Litela-HQ`). Cookies and logins are separate from ordinary tabs. Navigating to an unmatched URL does not automatically leave the current container. Container definitions and Containerise rules are replaced on activation (`containersForce` and extension `force`); edit the Nix file to make persistent changes. Keep container IDs stable to preserve their association with stored site data.

Firefox's `nix` profile keeps extensions, search engines, and bookmarks in `modules/features/browser/firefox/{extensions,search,bookmarks}.nix`. Edit the `tree` in `bookmarks.nix` to manage bookmarks, folders, and bookmarklets. Applying the configuration replaces existing bookmarks (`bookmarks.force = true`). Entries tagged `shortcut` also define pinned tiles for the built-in Firefox new-tab page, visible when New Tab Override is disabled; optional `icon` and `iconSize` fields customize their icons. Bookmarklets without that tag remain bookmarks only.

The profile uses [Parfait](https://github.com/reizumii/parfait), pinned in `modules/features/browser/firefox/parfait.nix`, following [natsukium's Firefox configuration](https://github.com/natsukium/dotfiles/tree/main/modules/features/browser/firefox). Home Manager deploys its CSS and assets to the profile's `chrome/` directory and merges upstream `user.js` defaults with local preferences. Blur and vertical tabs are enabled, with the sidebar hidden by default. Automatic translation prompts, spellchecking, and Firefox password saving are disabled. The bookmarks toolbar remains visible. Restart Firefox after applying theme changes.

Local preferences and CSS in `modules/features/browser/firefox/default.nix`, inspired by [nyanshiba's Firefox settings](https://github.com/nyanshiba/firefox-profile-settings), decode URLs on copy, insert new tabs after the current tab, and open bookmarks in new tabs. Local CSS is appended to Parfait's `userChrome.css` to widen the translation panel to `48em` and increase its text area height to `16em`.

Camera and microphone permissions default to blocked; screen sharing is disabled. The obsolete `canvas.capturestream.enabled` preference was removed; canvas stream capture is not blocked by this configuration. These settings affect web meetings and browser voice input. Query stripping is enabled in both normal and private browsing with the additional parameter names `s` and `t`; this list is not restricted to X/Twitter and can affect other sites that use those parameters. Apply with `nix run .#switch`, then restart Firefox.

Site-specific styles in `modules/features/browser/firefox/userContent.css` are appended to Parfait's `userContent.css`. Adapted from nyanshiba's settings, they cover X/Twitter (width, spacing, focus outlines, sensitive-content overlays, trends, and Spaces captions), YouTube, Amazon Japan, TradingView, Wikipedia, Nature/BioMed Central, Oura, oVice, IPinfo, speed-test sites, Google, OpenDNS, Tailscale, and the upstream WLX page at `http://192.168.100.21/`. Discord, Google Translate, DeepL, and the global PDF text-layer override are excluded. These selectors depend on each site's markup; hiding information is cosmetic and does not remove the underlying data. Restart Firefox after changing these styles.

Additional preferences disable Ctrl+wheel zoom and fullscreen transition fades, open PDFs with horizontal scrolling and odd-page spreads, and open PDF links in new tabs. Reader mode uses sans-serif text with content width `9` and line height `5`. Audio and video autoplay are blocked by default.

Normal searches use Google; private windows use the built-in DuckDuckGo engine (`search.privateDefault = "ddg"`). Standard DuckDuckGo remains a search candidate with the `@ddg` alias, alongside DuckDuckGo Lite. Separate private search is enabled with `browser.search.separatePrivateDefault.enabled` and `.featureGate`, verified in the installed Firefox 157.0 `SearchService.sys.mjs` and current Mozilla source. The legacy bare `separatePrivateDefault` and `.ui.enabled` names are not used.

Compatibility was checked on 2026-10-22 against the configured and installed Firefox 157.0 and current Mozilla source. The local preferences, PDF/reader values, and translation selectors were checked against the shipped code; Parfait-specific preferences remain tied to its pinned version. Fullscreen fade durations are already zero by default on GTK but are explicit here for consistent behavior across platforms. Site-specific CSS uses upstream selectors and has not been validated against current logged-in pages, so DOM changes may prevent individual rules from taking effect.
